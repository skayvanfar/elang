# elang

# Toy Language Parser and Lexer

## Overview

This project implements a simple interpreter for a toy programming language. The language supports basic arithmetic operations, variable assignments, and a `print` statement for output. The interpreter is built using **Flex** (for lexical analysis) and **Bison** (for parsing), which are tools commonly used for creating language parsers.

The app takes code written in the toy language, processes it using a lexer and a parser, and produces output or error messages based on the input.

## Features

1. **Variable Assignment:**
   - You can assign values to variables using the assignment operator (`=`). For example:
     ```plaintext
     x = 5;
     y = 10;
     ```
   
2. **Arithmetic Operations:**
   - Basic arithmetic operations are supported: addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
     - Example:
       ```plaintext
       z = x + y;
       ```

3. **Print Statement:**
   - The `print` statement can be used to output the value of variables or expressions.
     - Example:
       ```plaintext
       print(x);
       ```

4. **Expression Evaluation:**
   - Expressions like `x + y` or `5 * 2` are evaluated and their results can be assigned to variables or printed.

## How It Works

The app consists of two main parts:
1. **Flex Lexer**:
   - The lexer (generated by Flex) reads the input code, breaks it down into tokens (such as numbers, operators, and identifiers), and sends these tokens to the parser.
   
2. **Bison Parser**:
   - The parser (generated by Bison) receives the tokens from the lexer and applies grammar rules to interpret the structure of the code. Based on the grammar, the parser can perform assignments, evaluate expressions, and handle `print` statements.
